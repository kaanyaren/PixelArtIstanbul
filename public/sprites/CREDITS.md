# Sprite Credits — OPTIONAL upgrades only

The game works WITHOUT any of these. All in-game NPC sprites are
procedural (Phaser `Graphics` / `generateTexture`, no PNGs), so there
is zero license risk in the default build.

Only download one of these if you want a prettier drop-in replacement.
Each is free; check the linked page for its exact license before use.

## 1. (OPTIONAL) itch.io CC0 16x16 tag — character / tileset upgrades
- Browse: https://itch.io/game-assets/assets-cc0/tag-16x16
- License: CC0 1.0 Universal (per-item; confirm on the item page)
- Use: 16x16 character sprites to replace procedural cats / player

## 2. (OPTIONAL) Pipoya — FREE RPG Character Sprites 32x32
- Page: https://pipoya.itch.io/pipoya-free-rpg-character-sprites-32x32
- License: Free for commercial and personal use (Pipoya custom free
  license — NOT CC0; credit/terms on the item page)
- Use: 32x32 4-direction characters (64 chars) for NPC upgrades

## 3. (OPTIONAL) icebox91 — Free 16x16 Pixel Art Tilesets
- Page: https://icebox91.itch.io/free-16x16-pixel-art-tilesets
- License: Free for commercial and personal use, no credit required
  (CC0-like; confirm on the item page)
- Use: 16x16 tiles / props to dress streets around the NPC paths

## Rule
Never commit a downloaded sprite without adding its name, URL, and
license to this file first.
